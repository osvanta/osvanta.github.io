# osvanta.com

Source of the Osvanta website, built with [Astro](https://astro.build) and published to GitHub
Pages by the workflow in `.github/workflows/deploy.yml` on every push to `main`.

```bash
npm install
npm run dev      # local preview
npm run build    # output in dist/
```

The user guide at `/bus-log-analyzer/` is published by the
[bus-log-analyzer](https://github.com/osvanta/bus-log-analyzer) repository. Do not add a page or a
`public/` folder with that name here.
